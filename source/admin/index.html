连接你的博客仓库

只需一次性创建一个访问令牌，之后所有写作都在本页完成，不会再跳转 GitHub。

  1. 打开 GitHub Token 创建页
  2. Repository access 选择 Only select repositories，选中 hongming351.github.io
  3. Repository permissions 里把 Contents 设为 Read and write
  4. 点击 Generate token，把 github_pat_... 粘贴到右上角输入框并点「连接」

Token 只保存在当前浏览器（localStorage），不会写进仓库，也不会上传到任何服务器。没有 Token 的访客无法修改任何内容。
